# Template report

Nguyễn Thúy Ngọc · 20/11/2026

Mỗi report chỉ nên đọc trong 1–2 phút. Ghi kết quả (cái gì xong, link ở đâu), không ghi quá trình.

## 1. Daily report

Gửi cuối ngày.

```
[Daily] DD/MM/YYYY - Nguyễn Thúy Ngọc

Hôm nay đã làm:
- <việc 1> - <xong / đang làm x%> - <link GitHub / ticket>
- <việc 2> - ...

Học được:
- <1-2 ý chính>

Vướng mắc / cần hỏi:
- <vấn đề> - <đã thử gì> - <cần anh hỗ trợ gì>   (không có thì ghi "Không")

Ngày mai:
- <việc 1>
- <việc 2>
```

### Ví dụ

```
[Daily] 20/11/2026 - Nguyễn Thúy Ngọc

Hôm nay đã làm:
- Tổng hợp kiến thức 5 tuần - xong - onboard-preparation/01-tong-hop-5-tuan.md
- Research Hexagonal + TDD, so sánh Clean Architecture, có ví dụ từ login bot tuần 5 - xong - 02-hexagonal-architecture.md
- Research MoSCoW + các framework scope/time, ví dụ phân loại feature login bot cho 2 tuần - xong - 03-moscow-scope-time.md
- Chuẩn bị câu hỏi cho anh - xong - 04-cau-hoi-cho-mentor.md

Học được:
- Hexagonal và Clean Architecture cùng một nguyên lý: nghiệp vụ không phụ thuộc hệ thống bên ngoài; Clean chia thêm tầng bên trong.
- Khi thời gian cố định thì chỉ co phạm vi; Must nên ≤ 60% công để còn khoảng đệm.

Vướng mắc / cần hỏi:
- Không

Ngày mai:
- Đọc tài liệu về CRM (lead / thanh toán) và luồng enroll
```

## 2. Weekly report

Gửi cuối tuần.

```
[Weekly] Tuần DD/MM - DD/MM/YYYY - Nguyễn Thúy Ngọc

1. Mục tiêu tuần và kết quả
| Mục tiêu | Kết quả | Ghi chú |
| <mục tiêu 1> | Xong / Đang làm / Chưa làm | <link / lý do chưa xong> |

2. Số liệu ticket (khi đã lên công ty)
- Đã xử lý: <n> ticket   · Đang xử lý: <n>   · Chuyển người khác: <n>
- Theo hệ thống: CRM <n> · LMS <n> · TMS <n> · Khác <n>
- Ticket lặp lại nhiều nhất: <vấn đề> (<n> lần)
- Ticket tốn thời gian nhất: <#id> - <vấn đề> - <thời gian>

3. Bài học / phát hiện
- <điều mới về nghiệp vụ / hệ thống>
- <ý tưởng cải tiến nếu có, kèm số liệu>

4. Khó khăn và rủi ro
- <vấn đề> - <ảnh hưởng> - <đề xuất>

5. Kế hoạch tuần sau
- <mục tiêu 1>
- <mục tiêu 2>

6. Cần anh hỗ trợ / câu hỏi
- <câu hỏi>
```

Ghi chú:
- Trước khi lên công ty thì bỏ mục 2.
- Mục 2 và 3 là dữ liệu để chọn cải tiến ở tuần 5 đi làm.
